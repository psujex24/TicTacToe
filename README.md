Tic Tac Toe w C++ ❌⭕️

Prosta gra w kółko i krzyżyk stworzona w języku C++ jako część nauki programowania obiektowego. Projekt inspirowany materiałami z kursu Mirosława Zelenta (Pasja Informatyki), skupiającego się na klasach, dziedziczeniu i podstawach logiki gry.

🎥 Demo

Zobacz, jak działa aplikacja:  
https://youtu.be/eroPAx1XtlQ

🎓 Kontekst

Ten projekt powstał w ramach kursu programowania obiektowego w języku C++ prowadzonego przez Mirosława Zelenta. Jego celem było zastosowanie paradygmatu OOP w praktyce, poprzez stworzenie klasycznej gry logicznej z prostym interfejsem tekstowym.

🛠 Funkcje gry

- Tryb dla dwóch graczy (lokalnie)
- Plansza 3x3 w terminalu
- Obsługa wygranej i remisu
- Prosta i czytelna struktura kodu

🧰 Wymagania

- Kompilator C++ (np. MinGW, g++, MSVC)
- Środowisko programistyczne lub terminal z dostępem do kompilatora

🚀 Kompilacja i uruchamianie

1. Sklonuj repozytorium:
   git clone https://github.com/psujex24/TicTacToe.git
   cd TicTacToe

2. Skompiluj program:
   g++ main.cpp -o tictactoe

3. Uruchom grę:
   ./tictactoe

⚠️ Uwaga

Projekt ma charakter edukacyjny i może zawierać uproszczenia. Gra działa w trybie tekstowym i służy jako ćwiczenie z programowania obiektowego.

✅ Status projektu

Projekt został zakończony i nie jest aktualnie rozwijany. Stanowi zamknięty etap w nauce języka C++.
